# Stowarzyszenie Walki z Rakiem Płuca

Oficjalna strona internetowa Stowarzyszenia Walki z Rakiem Płuca.

## Stack techniczny

- Vite
- TypeScript
- React
- shadcn/ui
- Tailwind CSS

## Uruchomienie lokalne

Wymagania: Node.js oraz npm.

```sh
npm install
npm run dev
```

## Build produkcyjny

```sh
npm run build
```
